Data & keselamatan

Privasi

Ringkasan mudah tentang cara aplikasi mengendalikan data.

Data setempat

Nama paparan, tetapan, bookmark, nota, kiraan zikir dan kemajuan pembelajaran disimpan dalam storan pelayar pada peranti anda.

Lokasi

Jika anda memberi kebenaran, lokasi peranti digunakan untuk mendapatkan koordinat bagi waktu solat dan arah kiblat. Aplikasi tidak mempunyai server peribadi untuk menyimpan koordinat anda.

API pihak ketiga

Data waktu solat dan Al-Quran diperoleh melalui perkhidmatan API yang dinyatakan pada halaman Sumber & API.

Padam data

Gunakan Tetapan → Padam semua data untuk memadam data NUR Academy yang disimpan dalam pelayar ini.

Penggunaan

Terma Penggunaan

Gunakan aplikasi ini sebagai alat bantuan, bukan sumber hukum tunggal.

  1. NUR Academy ialah aplikasi pembelajaran dan utiliti, bukan aplikasi rasmi mana-mana institusi agama.
  2. Waktu solat bergantung pada lokasi, kaedah pengiraan dan data perkhidmatan yang digunakan. Semak waktu rasmi pihak berkuasa agama tempatan jika diperlukan.
  3. Kandungan pembelajaran adalah asas dan tidak menggantikan bimbingan guru atau rujukan fiqh berautoriti.
  4. Perkhidmatan internet dan API pihak ketiga boleh mengalami gangguan atau perubahan.
  5. Pengguna bertanggungjawab memastikan tetapan lokasi dan penggunaan aplikasi adalah sesuai dengan keperluan mereka.

Bantuan

Bantuan & FAQ

Jawapan ringkas untuk masalah biasa.

Kenapa waktu solat tidak muncul?

Semak sambungan internet dan pastikan lokasi telah ditetapkan.

Kenapa GPS tidak berfungsi?

Pastikan browser mempunyai kebenaran lokasi dan peranti mempunyai fungsi lokasi yang aktif.

Boleh guna tanpa internet?

Shell aplikasi boleh dibuka, tetapi data langsung seperti waktu solat dan kandungan Al-Quran memerlukan internet apabila data tersebut belum tersedia secara tempatan.

Kenapa notifikasi tidak muncul?

Notifikasi bergantung pada sokongan browser, permission dan keadaan halaman. Static web tidak boleh menjanjikan jadual background ketika browser ditutup sepenuhnya.

Boleh pasang NUR Academy?

Ya, jika browser dan hosting HTTPS menyokong pemasangan PWA.

Adakah Arah Kiblat menggunakan sensor kompas?

Ya, jika peranti dan browser menyokong sensor orientasi. Jika tidak, aplikasi masih menyediakan bearing geografi sebagai fallback.
