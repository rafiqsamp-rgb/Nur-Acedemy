# NUR Academy App Edition

Ini ialah versi mobile-app-ready NUR Academy V14.1 menggunakan Capacitor.

Web app asal dikekalkan; project ini hanya menambah lapisan Android supaya ia boleh dibina menjadi APK/AAB.

Quick start:

1. `npm install`
2. `npx cap add android`
3. `npx cap sync android`
4. `npx cap open android`
5. Android Studio → Run atau Build → Generate Signed Bundle / APK
